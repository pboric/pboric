### Petar Krešimir Borić

Environmental engineer and data scientist from Zagreb, Croatia. I work as a Research Assistant at the [Institute for Medical Research and Occupational Health (IMI)](https://www.imi.hr/en/), where I analyse air-quality data and calibrate measuring instruments.

Before that I managed a wastewater treatment plant, worked with sensor data as an intern at Oxyle in Zurich, and completed the Data Science & AI programme at Turing College.

**Tools:** Python · pandas · scikit-learn · LightGBM · PyTorch · Hugging Face Transformers · SQL · PySpark

#### Main project

**[pm-sensor-correction](https://github.com/pboric/pm-sensor-correction)**: corrects low-cost PM sensors against official EEA reference stations during Saharan dust, smoke and humid air, using weather data and Copernicus CAMS forecasts. Tested on areas the model never saw, a LightGBM model cuts the PM10 error in dust episodes by 40% compared with the standard humidity correction.
